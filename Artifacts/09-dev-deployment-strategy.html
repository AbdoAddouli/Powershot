Key Deployment Commands

Step Command Purpose
Authenticate sf org login web -o "ouil gas" -d Authorize the main Energy project org and set as default
Deploy Full sf project deploy start -d "force-app\main\default" -o "ouil gas" --wait 60 Deploy all metadata to the org (full deployment)
Deploy Single Path sf project deploy start -d "force-app\main\default\PATH" -o "ouil gas" Deploy a specific component or directory
Run Tests sf apex run test -o "ouil gas" --result-format human --code-coverage Run all Apex tests with code coverage report
Static Analysis sf code-analyzer run --config-file code-analyzer.yml --workspace . Run PMD/CPD static analysis on Apex code
Check Deploy Status sf project deploy report Check the status of a recent deployment
Package Manifest Deploy sf project deploy start -x "manifest/package-full.xml" -o "ouil gas" Deploy using package.xml manifest (12 manifests available)

17 Manual Post-Deployment Steps

These steps cannot be automated via CLI and must be performed manually in the Salesforce Setup UI after deployment.

1. Configure Slack webhook URL in Named Credential
2. Configure WhatsApp Cloud API token in Named Credential
3. Configure GA4 measurement ID in GTM_Config__c
4. Configure GTM container ID in GTM_Config__c
5. Activate HSE_Incident_Escalation flow (deploys as Draft)
6. Configure SCADA bridge secret in SCADA_Config__c
7. Assign page layouts to profiles
8. Wire Agentforce subagent bindings in Agentforce Builder UI
9. Configure Experience Cloud branding and theme
10. Set up JV_Partner_Sharing sharing set activation
11. Configure OilPriceAPI key in Named Credential
12. Configure EIA API key in Named Credential
13. Configure Petrel API credentials in Named Credential
14. Configure EPA CDX credentials in Named Credential
15. Assign permission sets to initial users
16. Create Public Groups (Executive Leadership, HSE Compliance Team)
17. Activate scheduled flows and verify cron jobs
Known Gap: Apex test coverage is currently ~39% (75% required for production deployment). All 14 test classes must pass, and additional test coverage must be written before production deployment.
