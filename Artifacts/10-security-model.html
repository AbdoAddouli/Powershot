Salesforce Security Layers

PowerShot implements a defense-in-depth security model with 6 layers. Each layer progressively narrows or broadens access. The combination of all layers determines what a user can see and do.

1
Layer 1 — Org-Wide Defaults (OWD) — Baseline Sharing

OWD defines the most restrictive default access level for each object. All records are private to the owner unless overridden by higher layers.

Security Principle: Only the System Admin (O_G_All_Access) has access to external credentials for API integrations. All other roles execute business logic via permission-set-granted Apex classes, which internally use Named Credentials for authenticated API calls. This ensures no user can make unauthorized external API calls.
