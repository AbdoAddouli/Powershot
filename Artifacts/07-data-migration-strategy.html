Phased Deployment & Migration Approach

PowerShot follows a dependency-ordered deployment sequence. Each phase must complete successfully before the next begins. The order is: Objects → Classes → Flows → UI → Security → Integrations → Agentforce → Experience Cloud.

PHASE 1 Week 1-2
Foundation — Data Model & Core Objects
Deploy all 30 custom objects, custom settings, platform events, page layouts, tabs, and custom app. This establishes the data foundation that all subsequent phases depend on.
Account Contact Asset Opportunity Case WorkOrder Well__c Well_Operation__c Pipeline__c Pipeline_Station__c Measurement__c HSE_Incident__c Regulatory_Permit__c Lease__c + 16 more objects
PHASE 2 Week 3-4
Business Logic — Apex Classes & Triggers
Deploy all 60 Apex classes (services, controllers, batch, queueable, test) and 9 triggers. Run Apex tests to verify business logic. Target: 75% code coverage for production deployment.
WellStatusService HSEIncidentService ComplianceDueDateService InspectionService InventoryBalanceService ProductionAllocationService RoyaltyCalculationService PermitToWorkValidationService PipelineIntegrityService + 9 triggers + 51 more classes
PHASE 3 Week 5
Automation — Flows & Scheduled Jobs
Deploy all 11 flows (7 scheduled + 4 record-triggered). Verify flow execution and scheduled job activation. This phase activates the time-based automation layer.
Compliance_Calendar Inspection_Due Joint_Venture_Billing Land_Lease_Expiration Production_Reconciliation Retail_Inventory_Alert HSE_Critical_Slack_Alert Field_Service_Dispatch HSE_Incident_Escalation Permit_to_Work_Approval Regulatory_Permit_Compliance
PHASE 4 Week 6
User Interface — LWC, FlexiPages & App
Deploy 15 LWC components, 8 FlexiPages, the PowerShot custom app, 25 tabs, and 25 page layouts. This phase makes the solution visible and usable by end users.
complianceCalendar fieldServiceChecklist hseIncidentMap inventoryTankGauge marketDataHome permitToWorkBoard productionAllocationReport wellProductionChart + 7 portal/store LWCs
PHASE 5 Week 7-8
Security, Integrations & Agentforce
Deploy 20 permission sets, sharing rules, sharing sets, named credentials, external credentials, remote sites, auth providers, Agentforce bot (1 bot, 8 GenAI functions, 12 plugins), and Experience Cloud portal. Configure post-deployment secrets.
20 Permission Sets 10 Sharing Rules (stubs) JV_Partner_Sharing Set 9 Named Credentials 7 External Credentials 6 Auth Providers O&G Operations Assistant Bot Experience Cloud Portal
