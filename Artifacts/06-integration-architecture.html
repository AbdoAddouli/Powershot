Authentication Methods

HMAC-SHA256
Hash-based Message Authentication Code — each request is signed with a shared secret to prove authenticity and prevent tampering.
Used by: SCADA/PI Ingestion API, WhatsApp Webhook
OAuth 2.0
Industry-standard authorization framework — Salesforce acts as OAuth client, exchanging tokens with external providers.
Used by: Petrel, EPA CDX, WhatsApp, GA4, GTM, DevOps Center
Named Credentials
Salesforce-managed authentication store — credentials are encrypted and never exposed in Apex code. Supports OAuth, Basic, and API Key auth.
Used by: 9 Named Credentials across all outbound integrations
Webhook URL
Simple URL-based integration — the webhook URL itself serves as the authentication token. Used for lightweight outbound notifications.
Used by: Slack HSE Alert webhook

Integration Patterns

Request-Reply
Synchronous REST callouts from Apex to external APIs. Used for real-time data lookups.
SCADAIngestionAPI, WhatsAppWebhookHandler, CommodityPricingService
Async Queueable
Asynchronous processing via Queueable Apex — decouples long-running integrations from user transactions.
PetrelWellSyncQueueable, CommodityPriceSyncQueueable, SlackAlertQueueable, EIAQueueable, ProvisioningQueueable, RenewalReminderQueueable
Platform Event
Event-driven architecture — platform events decouple publishers from subscribers. Used for cross-boundary alerting.
Slack_Alert__e → SlackAlertEventTrigger → SlackAlertQueueable
Scheduled Batch
Batch Apex for bulk data processing — rollups, integrity checks, reconciliation of large datasets.
PipelineIntegrityBatch, WellProductionRollupBatch, WellProductionTelemetryRollupBatch
Scheduled Apex
Time-based triggers — schedulers run at defined intervals to sync external data or trigger notifications.
CommodityPriceSyncScheduler, EIAPriceSyncScheduler
Webhook (Inbound)
REST endpoint exposed by Salesforce — external systems POST data to Apex REST classes.
SCADAIngestionAPI (@RestResource), WhatsAppWebhookHandler
